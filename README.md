# iReal Pro Flatpak

Unofficial Flatpak packaging and automated build workflow for [iReal Pro](https://irealpro.com/) on Linux.

## 🚀 Quick Install

If you want to test the latest `.flatpak` build generated by GitHub Actions:

1. Download `irealpro-flatpak.zip` from the **Artifacts** section of the latest run on the **[Actions Tab](../../actions)**.
2. Extract the zip file and install the bundle locally:

```bash
flatpak install --user com.irealpro.flatpak
```

3. Launch the application:

```Bash

flatpak run com.irealpro
```

## 🛠️ Local Building
Prerequisites

 - flatpak
 - flatpak-builder
 - Flathub remote configured

```Bash

flatpak remote-add --user --if-not-exists flathub [https://dl.flathub.org/repo/flathub.flatpakrepo](https://dl.flathub.org/repo/flathub.flatpakrepo)
flatpak install --user flathub org.freedesktop.Sdk//24.08 org.freedesktop.Platform//24.08
```

## Build & Install

Calculate the latest RPM hash and run flatpak-builder:
```Bash

# Get current SHA256 of the RPM
curl -sL [https://linux.irealpro.com/irealpro-latest.x86_64.rpm](https://linux.irealpro.com/irealpro-latest.x86_64.rpm) | sha256sum

# Replace PLACEHOLDER_SHA256 in irealpro.yml with the hash, then build:
flatpak-builder --user --install --force-clean build-dir irealpro.yml
```
